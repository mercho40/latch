# Using Latch

Behaviour of the macOS app as it ships today.

## Sessions and agents

Choose a workspace folder and select fx, Codex, Claude Code, OpenCode, or a custom ACP agent. Opening a session connects its locally discovered default harness; selecting another harness connects it immediately. Model and effort options load before the first prompt. Send only sends to an already-connected session and never starts or retries a connection. Stop cancels setup or the active response without losing an unsent draft. Reselect the harness in the toolbar to rescan and retry. Settings → Agents (⌘,) lists every agent with one line about its state and a switch for whether the agent menu offers it, and holds the custom command. Reselecting an already-connected harness rescans but keeps the live session, its history, and any unsent draft. You can switch harnesses while idle or connecting. New sessions remain available from the toolbar or ⌘N. With no session selected, the window asks what to build and lists up to five recent workspaces, each one click from a new session there; New Session… chooses any other folder. Close one with ⌘⌫, the sidebar's context menu, or File → Close Session: its agent stops and it leaves the saved library, and ⌘Z reopens it in the same place with its title, transcript, unsent draft, and agent context. The window reopens at the size and position it was left at.

Built-in setup is automatic: Latch reuses an installed integration or silently starts the pinned fallback on first connection. There is no installation dialog or adapter confirmation, and built-in launch commands are not shown; where an installed agent was found is in its row's tooltip in Settings → Agents. For Codex, sign in with `codex login`; for Claude Code, set up your Claude login and Node.js 22+. First-time setup may need Node.js with npm and internet access. fx and OpenCode use their installed commands and existing provider authentication. Missing prerequisites and startup failures appear in a banner above the conversation: the agent's own words on one line in monospace, then one line of advice, then Retry and Agent Settings…. After installing a prerequisite, press Retry or select the agent again to rescan.

Custom ACP Agent runs any ACP server. Set its command in Settings → Agents by typing it or choosing an executable; the command is saved and used by every session that selects the custom agent. Commands support quotes and backslash escaping, not shell expansion or pipelines. On disconnect the transport closes stdin and sends SIGTERM to the agent's process group, then force-kills the group if the agent has not exited within five seconds; a tool child the agent started that is still running then is killed with it.

## Sidebar

Sessions are grouped by workspace, each row a title over the agent's name. A session at rest shows how long ago it was last active on the right of its title — "now", "5m", "3h", "2d", "3w", then a date — counted from the last prompt sent or turn finished. That slot gives way to anything that needs you: a spinner while connecting or working, with the second line counting the turn ("Working · 1m 12s"); an orange mark while a permission decision waits; a red one for a failure; and an accent dot, with the title in bold, for a reply that finished while another session was on screen. Under the pointer the slot becomes a close button. Times from before this was kept are not shown until the session is next used.

## Attention

Sessions keep running while Latch is behind another app, so attention comes to you. A permission request, or a finished turn, in a session you are not looking at posts a notification; Allow Once and Reject Once sit on the notification itself, while clicking its body only brings the session forward, because approving something unread is not a decision. Notification text names the workspace folder and nothing else — no prompt text, tool name, or argument. The Dock icon badges how many sessions are waiting for a decision and bounces once when one arrives in the background. A menu bar extra lists every session with its state and leads back to any of them; hide it from its own menu, and View → Show in Menu Bar brings it back. While it is showing, closing the window no longer quits Latch. The SwiftPM preview has no bundle identifier and therefore posts no notifications; the Dock badge and the menu bar extra still work.

## Menus, drag and drop

The Session menu carries the session commands with keyboard equivalents: Attach Files… (⇧⌘A), Stop (⌘.), Fork Session (⌘⇧N), Disconnect, Rename…, Reveal Workspace in Finder, Open Workspace in Terminal, and Previous/Next Session (⌥⌘↑ and ⌥⌘↓), each disabled when it cannot run. A folder dropped on the sidebar or on the empty detail pane opens a session in it, as does one dropped on the Dock icon or opened from the Finder, and File → Open Recent lists the workspaces you have opened. Right-clicking a session offers rename, fork, reveal, open in Terminal, copy path, and close; right-clicking a workspace offers the workspace actions alone. Renaming is inline in the row, and Escape keeps the previous name.

## Find, App Nap, and saving

⌘F opens a find bar over the conversation. It matches the text that is actually on screen, case- and diacritic-insensitively, in reading order; ⌘G and ⇧⌘G step through matches and wrap at either end, showing each in a native find indicator. Collapsed tool rows are not searched because there is nothing on screen to reveal, and Escape or Done closes the bar. A prompt in flight is registered as user-initiated activity so App Nap cannot throttle streaming while Latch is in the background; the Mac may still sleep on its own schedule. Saving sessions holds off sudden termination for the length of the write.

## Conversation and composer

The quiet native chat uses one content column shared by the transcript and composer, selectable replies, and compact tool updates that sit together as a group. Code blocks are padded panels and quotes carry a bar; a failed or running tool says so in colour as well as in words. The window resizes to the full screen and the conversation fills the pane, replies included, so wide tool output, diffs and tables get the room; no content constraint may become the window's maximum width. Long tool titles are shortened in the middle, keeping their status, with the whole line in the tooltip. In dark mode the conversation sits on a page darker than the sidebar, running up under the toolbar. Process diagnostics are not included in the conversation. A session with no messages opens on a heading naming its workspace. The composer shares that column and offers native model, effort, and permission-mode pop-ups only where supported, each as wide as the title it shows, with each option's description as a second line in its menu: on macOS 26 and later they are the same Liquid Glass capsule as the agent control in the toolbar, and borderless before it. Controls have 36-point hit targets, wrapping onto another row in narrow windows rather than being squeezed. Return or ⌘ Return sends; Shift Return inserts a newline; Stop cancels the active response. Typing `/` at the start of an empty draft lists the commands the agent advertises, filtered as you type: the arrows move, Return or Tab chooses, Escape closes, and a chosen command shows what it expects next in grey. Files, folders and images can be pasted, dropped on the composer, or chosen with the paperclip or Session → Attach Files…; up to ten wait above the draft with a remove button each, and a message can be attachments alone. Images are scaled to at most 1568 pixels on the long edge and sent as images to an agent that accepts them, otherwise as a link to the file; files and folders go as links the agent opens itself. A sent message lists its attachments by name; image data is not saved, and attachments waiting in the composer are not kept with the draft. Each composer keeps its own undo stack, so ⌘Z there edits that draft and never reaches the session list. Spelling is checked, but nothing is rewritten: autocorrect, text replacement, and quote and dash substitution stay off for paths, flags, and identifiers. The header carries only the harness pop-up and status text. Native Markdown supports a subset of headings, emphasis, lists, quotes, links, and fenced code; it is not a browser or full CommonMark renderer. HTML and remote resources are not rendered or loaded. Per-message Copy preserves the original Markdown, while normal text selection copies the rendered text. Edit → Copy Conversation copies the retained messages and tool activity. Streaming follows the bottom unless you scroll up, with a round Jump to Latest arrow to return. History is bounded to 400 messages / 200,000 text characters and is saved with the session library in `~/Library/Application Support/Latch/sessions.json`. System colors and fonts follow macOS appearance; there is no web view or JavaScript UI.
